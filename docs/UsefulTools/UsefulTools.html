Useful Tools for Beginners in Computer Science

arrow_back

I am currently a third year Computer Science and Engineering student. Throughout the duration of my course there have been many skills I have picked up from the curriculum and otherwise. Along with those skills came some particularly useful tools which made the process of learning and making new things easier. This is a catalog of those tools, in no particular order.

Code Visualiser - Python Tutor

This website has a fairly limited but useful purpose of visualising your code execution. It supports languages like Python, C and more. It allows you to key in some lines of code in your language of choice and then it provides a step by step diagrammatic representation of what might actually be happening while that code executed. I found this particularly useful while learning concepts like callbacks, pointers etc.

Online Learning

Neso Academy

This particular youtube channel has a wide variety of lectures in topics of computer science. I found this channel while learning data structures for the first time. However, their videos were most useful for Computer Architecture and Microprocessing related subjects.

Like any mode of learning this is not guaranteed to suit everyone or every situation.

MIT Open Courseware

This platform is a highly useful one which houses a vast collection of real-time lectures from the MIT campus. Along with videos they provide worksheets and problem sets for each lecture for extra practice. To get a strong and complete understanding of any topic, this is a very good online destination.

HTML & CSS - Interneting is Hard

This website is a good precursor to beginning the web development journey. Though web development has many phases other than the front end, HTML and CSS is an integral part of the learning journey for web dev. This website makes it much easier to understand the intricacies of both technologies and is just a great confidence booster for a first time learner. Having the knowledge that it provides just makes it easier to focus on other parts while developing a web application without second guessing the syntax and semantics of plain HTML and CSS.

Computer networks - Jim Kurose

Learning how computer networking works can be difficult because it involves certain convoluted concepts which often need detailed practice and explanation to really drive the concept home. Jim Kurose from University of Massachusetts Amherst has written a really good book for first time learners of computer networks. Whats more is that all concepts are supported with online practice questions along with solutions for more clarity.

Web Development
CSS Flex box - A Complete Guide to Flex Box

Anyone who has worked with CSS would be aware that elements on a page can be arranged using grid , table , flex layouts etc. However, flex being a newer technology and more flexible is much easier to use. It allows you to make quite complex layouts which are also flexible. The best part is, most things that can be achieved using grid s and table s can also be accomplished by a flexbox . This website gives a succinctly put together guide for everything related to flex boxes with very clear images.

Color Palettes - Colorhunt

While designing any software while the functionality of the inherent application is important, the look and feel of the application also decides how customers favour the application. The colour scheme is one part of the interface which should be pleasant to look at. This website provides a wide range of colours with various tags to filter choices from to get the exact colour scheme you wish to use.

Google Fonts

In any documentation or any website, the fonts used give a distinct personality to the presented content that might even become attached to their brand image. Thus, the choice of font is an important one to make. Google fonts is easy to use and embed in a void variety of projects. They have good filters for picking the style of your choice. Along with fonts, they also provide various symbols that can aid the textual content.

Design Systems

Any web page’s design follows an underlying set of rules that is apparent on sufficient inspection. Though this seems trivial, it is actually very important. Design flaws in a page should not distract a viewer from the content.

However, all engineers may not want to spend time in constructing their own set of rules from scratch and then coming up with complete CSS for it. This is where the systems mentioned below become useful. They provide components with their own set rules which developers can utilise.

Material Design

This design system is provided by Google. So, if you require your application to look akin to Google’s design and aesthetic, this design system is the one to use.

Since it is provided by google it is best supported in Angular (which is also a google creation). However, there are provisions for using it in frameworks such as React too.

Bootstrap

This design language was created at Twitter. It looks significantly different from Google’s design system however it provides a pleasing minimalistic aesthetic.

It does not particularly gate-keep its accessibility like material design might seem to do for non-google frameworks so it might be suitable for other web dev stacks.

However there are certain components that are better implemented in Material Design than in Bootstrap and vice versa.

Version Control - Github

This tool is widely used in enterprises as it provides one of the most important features in a long term project - Version Control. With version control, all versions of changes made to files can be stored. So if you make a mistake, you can just revert back to the last good version.

If you can understand the technicality behind Git and services like Gitlab, Github, etc. this can be used for version control of any type of files used in any field and it is quite useful to track the history and progress of long projects.

Typing Diagrams - Mermaid Js

As in any field, more often than not one has to represent a system’s structure in the form of flow-charts or other diagrams to be able to put across information faster, and in a organised fashion.

If you are comfortable with typing out your instructions rather than dragging dropping squares and circles onto a canvas, Mermaid Js is perfect. It provides simple syntax to be able to type instructions to draw a figure rather then actually build it using a user interface!

Whats more is it is supported in markdown files so Github Readme’s can also utilise mermaid Js to make your repositories attractive.

Documentation

README - Markdown

As projects get larger and more contributors join the project, documentation has to increase so that all the people in a project can be on the same page before making big changes or additions to existing components.

In technical documentation the content obviously requires more focus than how it looks. A regular developer should not have to bother with page widths, text colours, fonts etc. while writing a document explaining the components of a project for fellow developers.

Thats where markdown comes in. Markdown was developed as a much more readable version of existing “markup” languages such as HTML, XHTML where the information is enclosed in tags making the text formatting heavy.

Now markdowns are very commonly used in “Readme” files of projects. They provide very simple formatting that aids the information representation without taking over completely.

It supports several features like code blocks, formatted headings etc. making it useful for technical writing in any field.

Equations - Latex

When the famous Donald Knuth went out to publish the second edition of his paper “ The Art of Computer Programming” he set out to create a new digital typography system that could match the typesetting technique used in the publishing of the first edition. This became “Tex” as described in a memo he wrote. Later on, a markup language called Latex was developed on this.

The point of the language was to be able to type out mathematic and scientific notation with ease. Most technical papers written today use this format sometimes through online editors such as Overleaf .

Even markdown documents allow addition of latex blocks. Thus, it is highly useful to get equipped with this language to speed up technical writing especially when using complex symbols and equations.

Text Editors

Finally, most of the work of a Computer Science student happens on a text editor of some kind. For those well versed in the workings of Unix shells it may be in editors such as vi or emacs for others it may be the widely popular editors such as VS Code, IntelliJ, Sublime Text etc.

The purpose of a good text editor is to be able to construct your program easily, while being able to follow all the constructs of the language of your choice. A text editor that works always, consistently is better than one with a hoard of features and frequent failures and confusions.

All the above points make the choice of text editor very personal. However, these are the factors I noticed in editors that I used

VS Code

My first language was Python. So I started on the default IDLE provided on the installation of Python. Very quickly I grew comfortable with it and moved on to VS Code.

VS Code is a very good editor for programmers writing their first ever programs. It provides a very nicely packed environment with as many features inbuilt as possible so that a beginner can focus on becoming comfortable with a new language or framework before understanding how various subsystems interact with each other, or how files are built etc.

  • For most recognisable languages VS Code has an internal build setup which is hidden behind a clean run button nicely abstracting the complexities of the build process.
  • You can make your interface feel at home by customising themes, icons etc.
  • VS Code tries very hard to make sure that a developer does not need to leave their application to do anything. They have an inbuilt terminal, several community and inbuilt plugins for various technologies, debugging features, version control support, collaboration etc.

VS Code is clearly a “Jack of All Trades”. But that also makes it a “Master of None”. As the complexities of your workflow increase, or if your tech stack is one of the unknown ones, VS Code can fall short.

In general though, VS Code seems to work well with tech stacks using python, javascript or other common frontend frameworks in web development.

IntelliJ

IntelliJ is one of those applications that a beginner does not use. It can be highly intimidating and also works well for a limited tech stack. But, whatever it does, it does absolutely perfectly.

  • The basic community IntelliJ is made for Java and Kotlin. It is also the editor used for major Android App Development.
  • Normally, Java is a language that takes time to understand even if it is the first thing you learn because it introduces the entire world of Object Oriented Design. IntelliJ makes this learning experience more convenient by providing many integrations within for creating Java projects, code completion, code refactoring etc.
  • One of the downfalls of IntelliJ is perhaps its strictness of following the Java project structure. While java programs can technically consist of just a single file that is simply compiled using javac to get the .class file, IntelliJ assumes that all programs are structured as projects with the correct directory structure.

Thus, it is definitely recommended for properly formatted large java projects as it provides all build, test, debugging features, however, not for one or two java files which are not in a well thought-out structure.

Just like VS Code IntelliJ also provides many community and inbuilt plugins to enhance the workspace.

The Originals - emacs & vi

The current text editors in the market are definitely successful but their success is nothing compared to their ancestors, emacs and vi . Both approaching almost half a century since their creation can be utilised within the Unix shell.

  • The various commands that they have created to manipulate text within their editors are very useful across other commands in the Unix environment.
  • These editors definitely have a learning curve, but understanding them unlocks skills that other new editors seldom provide.
  • They are very useful when performing complex text manipulation using regex, complex find and replaces etc. But given the existence of new editors today, one does not have to completely rely on them for every job.

Other than the above mentioned, there still exist many more editors such as Atom, Sublime Text etc. which are also worth exploring.
